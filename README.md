# 🚄 学生优惠 · 区间规划器（Student Rail Planner）

单文件网页应用：帮你规划 12306 **学生票优惠次数**的消耗 —— 在「学校端固定、家庭端可调」的前提下，
为每一趟想去的地方算出是**直达优惠、中转优惠还是全价**，并枚举全部车站作为区间端点，
找到**消耗优惠次数最少**的区间修改方案。

## 快速开始

- 直接双击打开 `index.html`（需要联网加载地图瓦片与 Leaflet）
- 或本地起一个静态服务器（推荐，避免个别浏览器的 file:// 限制）：

```bash
cd student-rail-planner
python -m http.server 8000
# 打开 http://localhost:8000
```

打开后自带演示数据：**学校=武汉 ↔ 家=长沙**，行程：北京 / 广州 / 重庆（往返）+ 西安（单程）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 🗺️ 地图与车站 | 高德/OSM 双底图切换；内置 367 个主要车站（35 个枢纽），图层可显示全部车站，点车站看详情 |
| 📍 区间设置 | 学校端固定；家庭端可输入地址（城市名直接离线匹配车站，任意地址走 OpenStreetMap 地理编码）或在地图上拖绿色图钉 / 点击地图放置 |
| 🧭 出行计划 | 添加想去的地方（城市名/地址/地图点击），每条行程可切换 往返/单程 |
| 🧾 规划结果 | 每条行程给出：直达里程、判定（直达优惠/经 XX 中转优惠/全价）、消耗次数；汇总总消耗、剩余次数（预算可调，默认 4 次/学年）、直达/中转/全价数量 |
| ⚡ 区间优化 | 枚举全部 367 个车站作为家庭端，三个视图：**最省次数 / 覆盖全部 / 离家最近**；"应用最优"= 不减少当前覆盖数前提下消耗最少 |
| 🎚️ 中转比例 | 中转绕行上限可在 1.1×~2.2× 之间调整（默认 1.5×），实时生效 |

## 计算规则（与界面内"计算规则"一致）

1. **优惠区间** = 学校↔家两座城市；学校端固定，家庭端可变（模拟 12306 中修改区间）。
2. **直达 = 1 次**：目的地位于区间沿线带内（垂直偏差 ≤ max(45km, 18%×区间长)）。
3. **中转 = 1 次**：经枢纽站 T 绕行后 `总里程 ≤ 比例×直达里程`（默认 1.5×），且 **T 贴近区间沿线**（偏差 ≤ max(70km, 32%×区间长)），自动选择最顺路的中转站。区间内任意站（含家庭端）均可作为换乘站。
4. **往返 = 2 次**（去 + 回），**单程 = 1 次**；未覆盖行程 = 全价购票、不消耗次数。
5. 距离为球面直线近似（Haversine），未考虑铁路实际走向。

## 出票规则速查（实测验证，2026-08-14）

| 情形 | 能否出票 | 实测依据 |
| --- | --- | --- |
| 区间内任意两站（含中间段 b-c） | ✅ 能 | 邢台→郑州（区间石家庄↔乌鲁木齐）615 赞；"一端是学校即可" |
| 区间内联程换乘（同一站、首末段 120h 内、中途可停留） | ✅ 能，扣 1 次 | 辽宁→北京→安徽隔几天算 1 次（677 评论帖） |
| 同城站互发（1 张内） | ✅ 能，不额外扣次 | 贵阳北⇀贵阳北环铁实测（307 赞帖评论） |
| 改家庭端后购票（旅游目的） | ✅ 能，即时生效 | 改区间后长沙→杭州成功；"另一端随便改"111 赞 |
| 两端都不在区间内 | ❌ 12306 拦截 | 海口→徐州提示"不在区间内"；需先改家庭端 |
| 区间设置小于购买区间 | ❌ 拦截 | 金华↔上海 买 温州→上海 失败 |
| 有未出行学生票订单时改区间 | ❌ 禁止 | "已买了未出行的学生票，不能再改区间" |
| 分段单独买（非中转模块） | ❌ 可能被拦 | "分段买被阻拦，联程买就可以" |
| 超出区间强行买（第三方/线下） | ⚠️ 能出但风险 | 实测无人查票；但"能出票不代表合规"、核验失败会被补差价 |
| 资质核验不通过 | ⚠️ 出票后闸机拦截 | "没核验成功进站台都进不去" |

## 技术说明

- 纯前端单文件，无后端、无 API Key
- 地图：Leaflet + 高德街道瓦片（国内加载快）/ OSM 兜底
- 地理编码：内置车站库离线匹配（城市名即时可用）→ 失败时回退 OpenStreetMap Nominatim
- 核心规划逻辑为纯函数（`STATIONS` / `planOneWay` / `evalWith`），便于测试与复用
- 界面按 [emilkowalski/skills](https://github.com/emilkowalski/skills) 仓库中的设计技能（`emil-design-eng` / `apple-design`）重做：
  浅色画布 + 白色卡片、黑色主按钮、大标题负字距/收紧行高、按下即反馈（100ms）、半透明毛玻璃导航、reduced-motion 兜底
